## Project Overview

This repository contains all project documentation, Agile framework implementation materials, training resources, Jira exports, sprint artefacts, retrospective reports, and configuration management records for the Agile Transformation Project developed as part of the ITSU2006 – IT Project Management group assessment.

The project focuses on implementing an Agile Project Management Framework within a software development team to improve collaboration, project visibility, delivery efficiency, and stakeholder engagement through the adoption of Scrum practices, Jira project tracking, and GitHub version control.
